# Personal Homepage

A lightweight, responsive academic homepage built with plain HTML and CSS. It is published directly through GitHub Pages and requires no build step or external framework.

## Development

Edit `index.html` for content, `styles.css` for presentation, and `assets/` for local images. To preview the site locally, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
